# PennPaws prototype

The clickable prototype the team agreed on before building, made in Claude Design.

**View it:** [PennPaws screens](https://claude.ai/artifact/WAwaUqNXrMKXGXrPKBLeB4). It opens for people Lu has shared it with.

This folder keeps the prototype's source, so the design is versioned next to the code. The `.dc.html` files run inside Claude Design, so open the link above to click through them.

| File | Screen |
|---|---|
| `SignIn.dc.html` | 0, signed out: what PennPaws is and Sign in with Penn |
| `Main.dc.html` | 1, post a request: the seven-question survey, clickable |
| `Browse.dc.html` | 2, open requests a sitter browses |
| `Detail.dc.html` | 3, request detail with I can help |
| `Agreement.dc.html` | 4, care agreement with two approvals, clickable |
| `canvas.json` | How the screens are laid out on the canvas |

Last updated Oct 31, 2026: "Pick my own dates" comes first, and the Thanksgiving and Winter break options were removed.
